Act II

The Magical Split Pools 🌊🌀

To avoid adjacent classmates, Seaty the Engine splits all students into two balanced queues: the Left Pool (Seat 1) and the Right Pool (Seat 2). Seaty makes sure that if there are multiple subjects, they interleave! If there's only one subject, it splits the queue down the middle so peers are separated.

Act III

Column-Continuous Harmony 🎯

Now, Seaty walks row-by-row and bench-by-bench. Instead of placing students horizontally (where copying is easy), the engine allocates them vertically down each column first! Left Pool students sit in Seat 1, while Right Pool students fill Seat 2. The result? Total academic integrity!

🛠️ System Tech Stack

Under the hood, Seat-Sync is built with enterprise-grade modern frameworks for blazing-fast computations.

React & HeroUI Frontend

Built with React 19, TypeScript, and HeroUI for highly dynamic, accessible, and interactive administrative consoles.

⚙️

Express & TSX Backend

Robust REST API endpoints and state machines built with Node, Express 5, and TSX-watch compilation.

Sequelize & SQLite DB

Lightweight, reliable SQL schema structures with automatic Sequelize synchronization, custom transactions, and deep indexes.
